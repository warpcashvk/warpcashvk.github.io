Les prix sont en monnaie du jeu. Les achats se font uniquement en jeu, sur les shops. Le « panier » du site est une simple liste qui reste dans ton navigateur : rien n'est commandé ni payé ici.

Services qui reçoivent ton adresse IP

Comme pour tout site, ton navigateur contacte quelques services pour afficher les pages. Chacun reçoit alors ton adresse IP et le type de ton navigateur. Le site ne leur envoie rien d'autre.

  • GitHub : héberge le site. Il conserve des journaux techniques pour la sécurité. GitHub est certifié Data Privacy Framework (transfert UE → États-Unis encadré). Voir sa politique de confidentialité.
  • VikingCraft (api.vikingcraft.fr) : prix, stocks, profils et classements en direct.
  • jsDelivr : les textures des items Minecraft.
  • cdnjs (Cloudflare) et VkAnalyzer : la carte, seulement sur la page Carte.
  • mc-heads.net : seulement en secours, si le skin d'un fondateur ne peut pas être chargé depuis le site.

Les polices sont hébergées sur le site lui-même : aucun appel à Google.
